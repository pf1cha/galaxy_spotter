# 🌟 Galaxy Spotter 🌟

> *Explore galaxy classification with your own object.*

Galaxy Spotter is an application that allows for classification of galaxies as elliptical or spiral from FITS images or user-supplied coordinates of the desired object.

## Features

- Processing of FITS images is automated
- Feature to supply coordinates
- Confidence of classification broken down
- Easy to save object image
